## 我们都在面对的烂摊子

你的笔记散落在各处。Apple Notes 里是购物清单。Google Docs 里是工作会议纪要。桌面上一个 txt 文件存着随手摘抄的句子。还有一个 txt 文件是项目灵感——也可能在 Notion 里？找一样东西要花五分钟搜索。要把两个想法跨应用关联起来更是不可能的，因为这些想法根本不知道对方的存在。

这就是 2026 年个人知识管理的默认状态：碎片化、孤立化、缓慢腐烂。你不停地记笔记，因为遗忘的感觉比收集更糟糕。但只收集不整理，那叫囤积。

Obsidian 能解决这个问题。不是给你的应用收藏再加一个，而是用一种根本不同的方式，取代那些应用在做的事。

## Obsidian 到底是什么

Obsidian 是一个 Markdown 编辑器。但这么说太屈才了。把它想象成 **一个本地优先的知识库，通过你建立的连接自然生长出结构。**

它有两个与众不同的地方：

- **你的笔记以纯 `.md` 文件的形式存在硬盘上。** 不在专属数据库里，不在你控制不了的服务器上。纯文本文件，任何编辑器都能打开，任何工具都能备份，永远归你所有。
- **笔记之间可以用 `[[wiki-links]]` 相互链接。** 当你在一篇笔记里输入 `[[特斯拉]]`，你就创建了一个双向连接。原笔记知道特斯拉的存在。特斯拉的页面也知道有哪些笔记链接到它。连接是双向的、自动的。

这两个特性——本地纯文本和双向链接——就是整个地基。Obsidian 的一切功能都建在这之上。

## 三个核心概念

### Vault

Vault 就是你电脑上的一个文件夹。就这么简单。里面每一个 `.md` 文件都是一篇笔记。你想要多少个 Vault 都行——工作一个、个人项目一个、研究论文一个。它们互不干扰，各自独立。

创建新 Vault：选一个空文件夹，或者一个已经有 Markdown 文件的文件夹。Obsidian 会扫描这个文件夹，把所有文件编入索引。

### Markdown

Markdown 是一种纯文本格式化语法。不用点加粗和斜体按钮，你输入 `**加粗**` 和 `*斜体*` 就行。标题用 `#` 号，列表用 `-`，链接是 `[文字](url)`。

Markdown 是面向未来的。如果 Obsidian 明天不在了，你的笔记仍然是纯文本文件，任何操作系统上的任何编辑器都能打开。二十年后，一个终端窗口依然能正确渲染它们。

### 双向链接

`[[维基链接]]` 是 Obsidian 力量的核心。当你从笔记 A 链接到笔记 B 时，Obsidian 会自动记录反向连接。笔记 B 会获得一个**反向链接**区域，显示所有引用它的笔记。

听起来很简单。但它改变了一切。不同于文件夹和标签——它们给你的笔记施加单一的层级结构——双向链接让你的知识像一张网一样生长。任何笔记都可以连接到任何其他笔记。一篇笔记可以属于多个上下文。连接在你写作的过程中自然涌现。

## 为什么双向链接很重要

**无需搜索就能发现。** 你打开一篇关于机器学习的笔记，滚动到反向链接区，发现三篇几个月前写的笔记引用了它。其中两篇你已经忘了。这不是记忆的失败——这是常态。双向链接让你想起已经遗忘的东西，而无需你事先知道它的存在。

**自涌现的结构。** 你不需要提前规划好文件夹层级。你只管写笔记，一边写一边建立链接，结构自然从链接中浮现。久而久之，主题周围会形成聚类。Graph View 以可视化图谱的形式呈现这一切。

**没有孤立笔记。** 一篇没有任何链接的笔记就是孤立笔记。每一个孤立笔记都是一座知识孤岛。Obsidian 内置的工具可以显示所有孤立笔记，确保没有内容被遗忘。如果一篇笔记值得存在，它就值得被链接。如果不值得，删掉它。

## 分步安装指南

1. **下载** — 打开 [obsidian.md](https://obsidian.md)，点击对应你操作系统的下载按钮（macOS、Windows、Linux）。
2. **安装** — 打开下载的文件，按安装向导操作。大约 30 秒。
3. **打开 Obsidian** — 应用启动后显示欢迎界面。点击"Create a new vault"。
4. **命名你的 Vault** — 取个名字（比如"我的知识库"），选一个存放位置。选空文件夹从头开始。
5. **开始写作** — `Cmd+N` 创建新笔记。用 `# 标题` 写标题，`**加粗**` 强调，`[[另一篇笔记]]` 链接到还不存在的笔记——点击这个链接时 Obsidian 会自动创建它。

就这些。你已经拥有了一个无需任何配置就能工作的 Vault。

## Obsidian 和其他应用的区别

| 功能 | Obsidian | Apple Notes | Notion | Evernote | Google Docs |
|---|---|---|---|---|---|
| 文件格式 | 纯 `.md` | 专属格式 | 专属格式 | 专属格式 | 专属格式 |
| 本地优先 | 是 | 部分（iCloud） | 否（云端） | 部分 | 否（云端） |
| 双向链接 | 原生支持 | 无 | 需配置 | 无 | 无 |
| Graph View | 内置 | 无 | 无 | 无 | 无 |
| 插件 | 2000+ 社区插件 | 无 | 有限 | 有限 | 无 |
| 离线使用 | 完整 | 部分 | 有限 | 部分 | 无 |
| 费用 | 免费（无需账户） | 免费 | 订阅 | 订阅 | 免费 |
| 导出自由 | 是（纯文本） | 否 | 有限 | 有限 | 有限 |

Apple Notes 适合快速记录。Notion 适合团队数据库。Evernote 在 2015 年很好用。Google Docs 适合实时协作。但它们都不是为个人知识管理设计的。Obsidian 是。

## Obsidian 不做什么

Obsidian 不是云服务。没有内置同步（有付费选项，或者你可以用 iCloud、Dropbox 或 Git）。没有实时协作。没有带筛选器和公式的结构化数据库——那是 Notion 的领域。没有内置 AI 功能。

这些不是弱点，而是取舍。Obsidian 选择本地优先的所有权而非便利性。选择简洁而非功能臃肿。选择通过插件扩展，而非把所有功能塞进核心应用。

## Graph View

打开 Graph View（`Cmd+G`），你会看到所有笔记和链接渲染成一个互动图谱。每篇笔记是一个节点。每一个 `[[链接]]` 是一条边。相关内容在视觉上聚集成簇。孤立笔记显示为孤零零的点。

Graph View 不是噱头。它是唯一一种一眼看清你的知识形态的方式。你能看到哪些主题你探索得深入（密集的簇）、哪些区域需要更多关注（连接稀疏的节点）、以及你的笔记是一张连贯的知识网还是一堆互不相干的文件。

## 插件扩展一切

Obsidian 的社区插件把它变成了一个平台。需要看板？有插件。日历视图？有插件。每日日记带写作提示？有插件。间隔重复闪卡系统？有插件。

社区插件超过 2000 个，在 Obsidian 里点两下就能安装。其中之一就是 **Karpathy LLM Wiki**，它把你的 Vault 变成一个由 AI 维护的 Wiki——不过那是下一篇文章的内容了。
